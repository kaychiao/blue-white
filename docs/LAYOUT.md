# 短笺与小宇宙的响应式布局

页面主角是写给 Fred 的短笺，数学图形是可以触碰的陪伴；外滩素描和天气作为轻量生活信息。

## 布局规则

| 网页可用宽度 | 布局 | 页面边距 |
| --- | --- | --- |
| 1024px 起 | 左侧短笺、右侧图形；顶端对齐，共用最大 1200px 容器 | 40px |
| 600–1023px | 单栏短笺；图形居中，素描和天气在其下并排 | 32px |
| 360–599px | 短笺 → 图形 → 素描 → 天气，依次垂直排列 | 24px |
| 359px 及以下 | 同手机单栏，缩小页边距 | 20px |

手机标题按完整句子自然换行并平衡行长，不强制把两个分句塞进两行。桌面标题按分句排列，在列宽内适度缩放，最小 32px；仍然放不下时允许换行。正文和展开天气随内容增长，不设固定高度或裁切。时钟在手机上使用上下两行的日期、时间，省去重复的模拟钟面。

想你指数继续沿用紧凑分组；窄栏里的私语换到下一行。交互按钮保留至少 44px 的点击区域，支持键盘焦点及减少动态效果。网页允许浏览器缩放，未限制用户缩放。

## 样式归属

- `assets/css/main.css`：唯一的页面布局、字号和响应式断点来源。
- `assets/css/time-theme.css`：时间配色及天空、素描的绘制样式，不覆盖主页面列宽或字号。
- `assets/css/longing.css`：想你指数内部排列、心跳和彩蛋样式。
- `assets/js/app.js`：桌面标题适配，手机保留自然文字流。

不要在时间主题中继续叠加页面布局补丁，否则不同宽度和时间段容易出现相互覆盖。

保留现有的四时配色，小字号操作色由强调色与正文色混合加深。以各时段的 surface 为背景，次要文字的对比度约为 5.73–7.43:1，操作文字约为 5.46–7.76:1；标题使用更大的字号承载强调色。

## 验证与发布

在 Chrome 浏览器中检查了 320、390、768、1024、1440px 宽度的长短标题、想你指数彩蛋和展开天气；检查页面与主要组件无横向溢出，并使用 390×844 设备模拟检查手机首屏。该验证不等于 iOS Safari / Android 真机测试。

`node scripts/build-site.mjs` 给页面引用的 JS / CSS 加入内容指纹。资源内容改变时版本会改变，避免用户同时加载旧样式和新页面。源文件路径保持简洁，本地直接打开仍可运行。
