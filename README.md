# Blue & White

写给 Fred 的蓝白色小页面：短笺、可以触碰的数学图形，以及生活里一点小小的惦记。

[打开网页](https://kaychiao.github.io/blue-white/)

## 藏起来的约定

### 520 秒：让一句话多陪你一会儿

自动换句间隔是 **520 秒，也就是 8 分 40 秒**，取“我爱你”的心意。

- 到期后换一套完整文案，图形不跟着切换。
- 切出浏览器标签页时暂停计时回调，回来后才检查：满 520 秒就换，没满就保留当前这段。
- 点击“换一段心情”可提前换句，并重新开始 520 秒。
- 520 秒切换的是已经生成的文案，不会每次都请求 AI。

实现位置：`assets/js/page-refresh.js`。

### 四颗星：不用写出来的“我在想你”

Fred 说过，**1111 是“我在想你”的意思**。页面用四颗星保存这个约定，不直接显示四个数字。

- **平时**：四颗稍亮的小星星散落在数学图形周围，所有图形都有。
- **自动触发**：每天上海时间 **11:11、23:11**，页面可见时，四颗星慢慢排成一线，各拖出一道细长的竖直光痕，依次亮起，暗示“四个一”，再散回原来的位置。上方随机显示一句含蓄的英文短句，约 8 秒后恢复当前图形的英文名称。
- **手动触发**：在图形上按住约 **1 秒**。松手不会误切换图形。键盘可在图形聚焦时按 **Shift + Enter**。
- **普通操作**：轻点仍是随机切换图形，拖动仍是旋转；移动超过 5 像素会取消长按。
- **避免打扰**：同一个标签页中，每个约定时刻只自动触发一次，刷新也不重播；在 11:11 或 23:11 这一分钟打开或返回页面仍能遇见。错过这一分钟不补播，后台也不播放。长按可以随时再次触发，正在播放时不会叠加。
- **减少动态效果**：四颗星与四道光痕静态排列并显示短句，不移动、不闪烁。

英文短句共有 24 句，包含 **You crossed my mind.**、**Thinking of you, quietly.**、**I saved a little starlight for you.** 等。每次触发按洗牌顺序取一句，一轮用完再洗牌，跨轮也避免紧接着重复；当前标签页刷新后保留抽取进度。短句库位于 `assets/js/starlight.js` 的 `whispers` 数组，全部为本地文案，不额外调用 AI。

彩蛋只改变右侧的星光和图形名称，不改左侧文案，不重置 520 秒计时，也不额外调用 AI 或申请权限。

实现位置：`assets/js/starlight.js`（时间、手势与四颗星）、`assets/js/scenes.js`（图形绘制接入）。时间以设备时钟为准，统一按 `Asia/Shanghai` 解释；同一时刻去重保存在当前标签页的 `sessionStorage`，存储不可用时仍会在当前页面内去重。

### 想你指数：一天慢慢累积，每一刻有一点心动

这是一个**浪漫的模拟数值**，不是实际心率或对感情的测量；不连接 Apple Watch、不采集身体数据、不额外调用 AI。

数字由五部分组成：

- **日夜曲线**：上海时间 00:00 约 91、03:00 约 78、06:00 约 72、09:00 约 80、12:00 约 84、15:00 约 85、17:00 约 88、20:00 约 91、22:00 约 92。各节点用平滑曲线相连；午夜衔接前一天，逐渐进入夜间低谷，不从 99 突然清零。这些是底色，显示值还会叠加下面的起伏。
- **呼吸起伏**：约 9.8 秒和 14.6 秒的两条小波叠加，幅度总计不超过 0.62 个百分点。保留一位小数，变化轻而缓。
- **偶然心动**：约每 3～7 分钟出现一次，持续 18～32 秒，轻轻升高约 1.1～2.8 个百分点后回落。按上海日期生成固定的伪随机时间表；同一天刷新不会重新抽签，后台不补播。
- **一点余温**：每次心动结束后，5 秒内留下最多 0.1 的原始增量，随后缓慢淡去；所有余温合计平滑限制在 2.6 个百分点以内。不会无限堆高，也不会在午夜重置。
- **相遇的偏心**：离开标签页至少 15 秒后回来，产生一次 24 秒的小波峰，前 12 秒显示“你一回来，心跳就漏了半拍。”；上海时间 **11:11、23:11** 的前 24 秒出现两次很轻的波峰，呼应右侧四颗星。不直接显示“1111”。

最终数值限制在 4.0～99.9 之间，再做平滑跟随。小爱心采用“两下轻跳、稍作停顿”的节奏，约为模拟的 60～90 次/分钟，随日夜、心动及轻微节律波动而变化；它与数字的呼吸节奏不同，避免像监测仪一样快速跳数。普通模式每 250 毫秒轻量更新，减少动态效果时停用爱心动画、每秒更新数字。后台停止更新，回来只计算当下的状态，不回放错过的心动。

### 小爱心：刻度有尽头，惦记没有

轻点“想你指数”左边的小爱心，数字会短暂变成 **∞**，随机出现一句私语，停留 **5.2 秒** 后恢复。8 句文案避免相邻重复；∞ 期间内部曲线仍继续，结束后回到当下平滑变化的指数，不重置 520 秒换句计时。按钮支持 Tab 聚焦后按 Enter / 空格，Escape 可提前收起；离开标签页会收起。提示只在文字改变时通知读屏，避免每秒重复播报。

实现位置：`assets/js/longing-model.js`（日夜曲线、呼吸、日期种子与余温）、`assets/js/longing.js`（交互、显示平滑与返回波峰）、`index.html`（双拍爱心与减少动态效果样式）。完全依赖设备时钟，统一按上海时间解释；返回波峰只存在当前页面内，不存储用户的浏览历史。

## 天气更新与降级

页面通过 `data/weather-config.js` 指定的 Cloudflare Worker 查询上海天气。打开页面立即请求；前台每 5 分钟更新；回到标签页时若距上次查询至少 1 分钟则再请求；手动刷新会实际查询接口。Worker 使用和风的实时观测和逐小时预报，同一边缘节点缓存最多 5 分钟。观测时间与查询时间分开展示，不将“刚查询”写成“刚观测”。

和风 Key 和 API Host 单独配置在 Cloudflare Worker 的环境变量中，GitHub Secrets 不会自动同步过去。部署与配置说明见 [天气 Worker](cloudflare/README.md)。网页只知道公开接口地址，不携带和风密钥。

连接失败时优先保留最新的有效观测，再使用发布快照或本地缓存。超过 90 分钟的观测会显示“较早数据”；超过 3 小时不显示降雨概率、也不依据旧观测给出穿衣建议；超过 24 小时隐藏数值。GitHub Actions 仍每半小时尝试生成备用快照，延迟不会影响已经接通的实时接口。

## 内容与设置

- [AI 文案配置](docs/AI-SETUP.md)：Gemini、私密背景与近况、生成审校规则。
- [响应式布局说明](docs/LAYOUT.md)：电脑、平板、手机的断点与排版规则。

- `data/daily-copy.js`：AI 不可用时的人工备用素材。

## 目录与本地开发

```text
index.html          页面入口，只保留结构和资源引用
assets/
  js/               页面逻辑、数学图形、心动算法
  css/              页面样式和随时间变化的主题
  images/           外滩素描等图片资源
data/               随网页发布的公开文案、配置及生成结果
docs/               AI、餐厅、节日等使用说明
content/            AI 写作偏好及本地私密输入，不发布到站点
scripts/            文案生成、天气获取、接口检查、站点打包
tests/              自动化测试
.github/workflows/  GitHub Actions 部署配置
```

日常改文案请编辑 `data/daily-copy.js`，生日与纪念日配置在 `data/holiday-config.js`。`data/generated-copy.js`、`data/weather-data.js`、`data/amap-config.js` 在 Actions 构建时更新，本地保留可运行的默认文件。

在仓库根目录执行 `python3 -m http.server 8000`，打开 `http://localhost:8000` 预览。页面也支持直接打开 `index.html`；浏览器定位与地图服务仍须满足 HTTPS / localhost 及高德域名限制。

`node scripts/build-site.mjs` 会重新生成 `_site/`，只复制 `index.html`、`assets/` 和 `data/`；源码文档、测试、私密输入及可选服务端代码不会随站点发布。构建脚本中的文件路径以脚本所在仓库为准。
